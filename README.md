# Excel AI 助手（网页版 v1.1）

一个在浏览器本地处理 Excel 的小工具：文件不上传服务器，打开即用。

## 能干什么（6 个模块）

1. 数据去重
2. 多表合并
3. 表头自动匹配
4. 清理空行空列
5. 数据清洗（空格、换行符、手机号格式等）
6. 名称清洗（v1.1 新增：全角转半角、去多余空格，找出疑似重复的名字，原表不动，只加"整理后""改动"两列）

v1.1 还加了"结果接力"：处理结果可直接当新表连做下一步，不用下载重传；修了 3 个 bug（按最小值保留留空行、长数字保护未传给清洗、AI 见"每个"误判统计）。

## 怎么用

直接用浏览器打开 `index.html` 即可；也可以开 GitHub Pages 在线访问。
上传表格 → 选模块处理 → 下载结果。全程本地处理，不上传服务器。

## 实测

7 条脏数据：改 4 条，揪出 3 组疑似重复。

## 技术

HTML + Tailwind CSS + SheetJS。开发中用 Gemini、Codex 辅助。
